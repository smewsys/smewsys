# SMEWSYS — Stitch Iteration Prompts

Use these after the initial generation. Apply one at a time and preserve the existing design.

## Refine visual consistency
“Keep the existing SMEWSYS layout and information architecture. Refine the visual system so typography, spacing, border radius, card padding, icon sizing, CTA hierarchy, and teal accents are consistent across the entire screen. Do not introduce new components.”

## Improve premium feel
“Make the interface feel more premium through typography, whitespace, alignment, grid discipline, and subtle surface contrast. Do not add gradients, excessive shadows, decorative blobs, or unnecessary animations.”

## Improve conversion
“Strengthen the primary conversion hierarchy. Make Start a Project the clearest CTA while preserving a restrained secondary action. Do not add additional CTA types.”

## Improve mobile
“Create a deliberate mobile composition for this screen. Stack sections according to content priority, keep touch targets at least 44px, preserve readable typography, prevent horizontal overflow, and make the mobile navigation clear.”

## Improve accessibility
“Improve accessibility without changing the visual identity. Increase insufficient contrast, add visible focus states, ensure semantic hierarchy, and make form controls and interactive elements easy to identify.”

## Reduce visual noise
“Reduce visual noise. Remove unnecessary decorative elements and excessive borders. Preserve information hierarchy, whitespace, and the SMEWSYS teal accent.”

## Preserve brand
“Do not change SMEWSYS brand colors. Keep #19B5A5 as the primary accent and #0B0D0E as the main dark color. Do not introduce a new brand palette.”

## Fix generic AI aesthetic
“Remove generic AI/SaaS visual clichés. Replace them with structured editorial layouts, real technology/product imagery, clean cards, diagrams where appropriate, and strong typography.”

## Keep consistency across pages
“Treat the existing SMEWSYS screen as part of a larger design system. Reuse the same header, buttons, cards, typography, spacing, footer, CTA hierarchy, icon style, and surface treatment.”
