# SMEWSYS — Recommended Screen Generation Order

1. Home — establishes the visual language.
2. Services Index — establishes service cards and section patterns.
3. Service Detail — establishes reusable content template.
4. Work — establishes project cards and filters.
5. Case Study — establishes editorial/detail pattern.
6. Process — establishes numbered methodology.
7. About — establishes brand/story sections.
8. Technology — establishes technical capability patterns.
9. Contact — establishes form system.
10. Legal/System — establishes utility templates.

Do not generate all pages independently from scratch. Use the approved Home screen as the visual reference for subsequent screens and explicitly ask Stitch to preserve the established design system.
